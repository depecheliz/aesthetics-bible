# Native brand assets

Source-of-truth renders for The Aesthetics Bible's native icon/splash/
favicon identity, generated by `scripts/generate-native-brand-assets.js`
from the same brand tokens the app UI uses (black `#0B0B0C`, champagne
`#C9A97E`, Playfair Display SemiBold / Montserrat SemiBold — see
`constants/theme.ts` and `components/brand/Monogram.tsx`).

## Files in this folder (source/reference — not read by Expo)

- `icon-master-1024.png` --- the full-bleed 1024×1024 master icon render.
- `android-adaptive-foreground-1024.png` --- transparent-background AB
  monogram, sized to survive Android's adaptive-icon safe-zone masking
  (circle / rounded-square / squircle).
- `android-adaptive-background-1024.png` --- solid brand-black fill.
- `android-monochrome-1024.png` --- white AB silhouette on transparent,
  for Android 13+ themed icons (the OS applies its own tint).
- `splash-source.png` --- the AB monogram with "THE AESTHETICS BIBLE"
  in the same restrained eyebrow treatment used on the Home screen,
  transparent background (Expo composites it over `app.json`'s
  `backgroundColor`).
- `favicon-master-256.png` --- bare AB monogram at a small size, for the
  web favicon.

## Runtime assets Expo actually reads (generated from the files above)

These live in `assets/` (top level, existing paths — unchanged in
`app.json`) and are what `app.json` points to:

- `assets/icon.png` --- from `icon-master-1024.png`, flattened (no
  alpha; iOS requires an opaque icon).
- `assets/android-icon-foreground.png` --- from
  `android-adaptive-foreground-1024.png`.
- `assets/android-icon-background.png` --- from
  `android-adaptive-background-1024.png`.
- `assets/android-icon-monochrome.png` --- from
  `android-monochrome-1024.png`.
- `assets/splash-icon.png` --- from `splash-source.png`.
- `assets/favicon.png` --- from `favicon-master-256.png`, flattened.

## Regenerating

```
npm install --no-save sharp @napi-rs/canvas   # not project dependencies
node scripts/generate-native-brand-assets.js
```

Edit the constants at the top of the script (colors, target widths) to
adjust sizing/weight, then re-run. Nothing here is hand-drawn artwork ---
it's a deterministic render of the existing brand system, so it can be
regenerated exactly if a token changes.

## Not touched by this

`assets/brand/campaign/` (approved editorial photography) and the raw
`Images/` directory are unrelated to this folder and were not modified.
